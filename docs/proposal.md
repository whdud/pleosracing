## 1. 앱 한 줄 소개

차가 멈춘 그 자리에서, 차가 바라보는 방향의 밤하늘을 그대로 보여주고, Gleo와 대화하며 별자리 이야기를 듣는 가족·차박용 천체 관측 앱입니다.

---

## 2. 기획 배경

**차박·캠핑·야간 드라이브에서 별을 보는 순간은 많지만, 제대로 즐기기는 어렵습니다.**

- **"저 별이 뭐지?"에 답하기 어렵습니다.** 하늘을 올려다봐도 어떤 별인지, 별자리가 어디인지 알기 어렵습니다. 아이가 물어보면 부모도 답하기 곤란합니다.
- **폰 별자리 앱은 차 안에서 불편합니다.**
  - 작은 화면을 한 사람이 들고 봐야 해서 가족이 함께 보기 어렵습니다.
  - 폰을 계속 하늘로 들고 있어야 하고, 밝은 화면이 어둠에 적응한 눈을 방해합니다.
- **차 실내가 관측 환경에 맞지 않습니다.** 실내등과 무드등이 밝으면 눈이 어둠에 적응하지 못해 별이 덜 보입니다. 조명을 일일이 찾아서 끄기도 번거롭습니다.
- **어디로 가야 별이 잘 보이는지 모릅니다.** 빛 공해가 적은 관측 명소나 천문대, 유성우 같은 천문 이벤트 정보를 따로 찾아야 합니다.
- **아이들에게 밤하늘은 좋은 이야깃거리지만, 들려줄 이야기가 준비되어 있지 않습니다.**

**차는 이 문제를 풀기에 가장 좋은 장소입니다.**
가족이 함께 볼 수 있는 큰 화면이 있고, 차의 위치와 방향, 실내 조명, 내비게이션, 음성 비서(Gleo)를 모두 활용할 수 있습니다.
차박과 캠핑이 대중적인 여가가 된 지금, 차 안에서 바로 쓸 수 있는 관측 경험이 필요합니다. [국내 캠핑·차박 인구 통계와 출처 기입]

## 3. 앱 주요 기능 및 차량 특화 요소

### 주요 기능

**① 지금 이 자리의 밤하늘**
- 차의 현재 위치(위도, 경도, 고도)와 현재 시각으로, 지금 이 자리에서 보이는 별, 별자리, 행성, 달을 실시간으로 계산해 보여줍니다.
- **차가 향한 방향을 기준으로 하늘을 펼칩니다.** 화면에 보이는 하늘이 앞유리 너머 실제 하늘과 같은 방향입니다.
- 화면을 끌어서 다른 방향을 보거나, 시간을 앞뒤로 돌려 "오늘 밤 10시의 하늘"을 미리 볼 수 있습니다.

**② 별자리 이야기 (아이 모드)**
- 별자리를 누르면 그림과 함께 이야기가 펼쳐집니다.
  - **그리스 신화**: 오리온, 큰곰자리와 작은곰자리, 페르세우스와 안드로메다, 카시오페이아 등
  - **우리 별 이야기**: 견우와 직녀(여름철 은하수), 북두칠성, 조선의 천문도 '천상열차분야지도'
- 계절별로 지금 보이는 별자리를 골라 이야기를 추천합니다.
- 이야기는 음성(TTS)으로 읽어주어, 아이가 화면을 보면서 들을 수 있습니다. 한 장을 다 읽으면 다음 장으로 저절로 넘어갑니다.
- 별이나 별자리를 누르고 **"설명 듣기"**를 누르면, 그 별이 지금 어느 쪽 하늘에 있는지와 함께 그 별·별자리에 얽힌 이야기를 읽어 줍니다. (예: 직녀성 → 오작교 이야기, 베텔게우스 → 언젠가 폭발할 거대한 별, 좀생이별 → 옛 농사 점) 밝은 별 20개, 별자리 20개의 이야기를 담았습니다.
- 본 별자리를 모으는 **별자리 도감(수집)**과 간단한 퀴즈로 다시 찾아볼 이유를 만듭니다.

**③ Gleo와 별 이야기 나누기**

Gleo Interface로 음성 명령 3가지를 연동합니다. (Gleo Interface의 앱당 최대 3개 기능 기준, 프로토타입에 구현 완료)

| Gleo 기능 (`schema.json`) | 사용 예 | 동작 |
|---|---|---|
| 별 설명 `DESCRIBE_SKY_OBJECT` | "글레오야, 이 별 뭐야?" / "직녀성에 대해 알려줘" | 이름을 말하면 그 별을, 말하지 않으면 화면에서 고른 별을 찾아 이름, 종류, 밝기, 거리, 방향과 이야기를 Gleo에 전달하고, Gleo가 자연스럽게 설명 |
| 천체 찾기 `FIND_SKY_OBJECT` | "글레오야, 목성 어디 있어?" | 화면이 해당 천체로 돌아가고, Gleo가 "남동쪽 하늘 30도 높이에 있어요"처럼 방향 안내. 지평선 아래면 지금은 안 보인다고 안내 |
| 별자리 이야기 `TELL_CONSTELLATION_STORY` | "글레오야, 견우와 직녀 이야기 들려줘" | 이야기를 열고 그 별자리가 잘 보이는 시간의 하늘로 이동한 뒤, 앱이 직접 이야기를 끝까지 읽어 줌 (Gleo는 조용히 대기) |

- "직녀성", "베가", "오리온", "오리온자리"처럼 우리말 이름, 영어 이름, '자리'를 뺀 이름을 모두 알아듣습니다.
- 관측 명소 찾기는 앱 화면의 버튼과 내비게이션 길안내로 제공합니다.

**④ 관측 모드 (실내 조명 연동)**
- 관측 모드를 켜면 실내등, 독서등, 무드등을 한 번에 모두 꺼서 눈이 어둠에 적응하도록 돕습니다.
- 관측을 마치면 각 조명을 원래 상태로 되돌립니다.

**⑤ 선루프 관측 모드**
- 선루프가 있는 차량에서 관측 모드를 켜면 **선루프 가림막(블라인드)이 자동으로 열리고**, 화면이 고개를 들듯 **머리 위 하늘**로 올라갑니다. 시트를 젖히고 올려다보는 실제 하늘과 화면 속 하늘이 그대로 겹쳐집니다.
- 사용자가 직접 가림막을 열어도 앱이 이를 감지해 머리 위 하늘로 화면을 올립니다.
- 비, 벌레, 실내 온도를 고려해 **유리는 자동으로 열지 않고**, 사용자가 원할 때만 열 수 있게 합니다.
- 관측 모드(조명 모두 끄기)와 함께 동작해 **차 전체가 작은 천문대**가 됩니다.
- 선루프가 없는 차량은 앞유리 방향 하늘 모드로 자동 전환합니다.

**⑥ 관측 명소와 천문 이벤트**
- 빛 공해가 적은 관측 명소, 공공 천문대, 국제 밤하늘 보호공원 등을 지도와 함께 안내하고, 바로 길안내를 시작합니다.
- 유성우, 개기월식, 행성 근접 같은 천문 이벤트 일정을 알려주고, 그날 가기 좋은 장소를 추천합니다.

**⑦ 정차 중 전용 & 안전 설계**
- 차량이 주행을 시작하면 화면을 숨기고, 다시 정차하면 이어서 볼 수 있습니다.
- 주행 중에는 Gleo 음성으로 "도착하면 볼 수 있는 별" 정도의 짧은 안내만 제공하는 것을 검토합니다. [주행 중 음성 안내 허용 범위 확인 필요]

### 차량 특화 요소 — 폰 앱과 무엇이 다른가

| 항목 | 폰 별자리 앱 | 별마중 (차량) |
|---|---|---|
| 방향 맞추기 | 폰을 하늘로 들고 있어야 함 | **차가 향한 방향**을 자동 반영 |
| 함께 보기 | 한 사람이 작은 화면을 봄 | 가족이 **큰 화면**으로 함께 봄 |
| 관측 환경 | 차 안 조명을 하나씩 찾아서 꺼야 함 | **실내 조명을 한 번에 모두 끄기** |
| 하늘 올려다보기 | 고개를 들고 폰을 머리 위로 | **선루프 가림막이 열리고** 천장 하늘과 화면이 겹침 |
| 이동 연계 | 장소를 따로 검색 | 관측 명소 추천 → **바로 내비 안내** |
| 조작 | 손으로 조작 | **Gleo 음성**으로 묻고 답하기 |

## 4. 주요 사용 시나리오

**시나리오 1. 가족 차박 — 아이와 별자리 이야기**
1. 주말 캠핑장에 도착한 가족. 해가 지고 차 안에서 쉬는 중에 7살 아이가 "저 반짝이는 별은 뭐야?"라고 묻습니다.
2. 부모가 별마중을 실행하자, 차가 향한 남쪽 하늘이 화면에 펼쳐집니다.
3. 관측 모드를 켜자 차 안의 불이 모두 꺼지고 **선루프 가림막이 열립니다.** 시트를 젖히고 누운 가족의 머리 위로 실제 별이 보이고, 화면도 머리 위 하늘로 올라가 같은 하늘을 보여줍니다.
4. 아이가 화면 속 가장 밝은 별을 누르고 "글레오야, 이 별 뭐야?"라고 묻습니다. Gleo가 "그 별은 여름철에 보이는 견우성이에요. 은하수 건너편의 직녀성과 1년에 한 번 만난다는 이야기가 있어요."라고 답합니다.
5. 아이는 '견우와 직녀' 이야기를 끝까지 듣고, 별자리 도감에 첫 별자리를 모읍니다.

**시나리오 2. 커플 야간 드라이브 — 관측 명소 찾아가기**
1. 금요일 저녁 드라이브 중인 커플. 정차한 휴게소에서 "글레오야, 근처에 별 보기 좋은 데 있어?"라고 묻습니다.
2. 별마중이 40분 거리의 관측 명소를 추천하고, 바로 내비 길안내가 시작됩니다.
3. 도착해서 주차하면 지금 그 자리의 밤하늘이 나타나고, 오늘 밤 잘 보이는 행성과 별자리를 알려줍니다.

**시나리오 3. 천문 이벤트 — 유성우 보러 가기**
1. 페르세우스자리 유성우를 앞두고, 별마중이 이벤트 일정과 가장 잘 보이는 시간대를 알려줍니다.
2. 사용자는 추천 장소로 길안내를 받아 이동하고, 도착하면 유성이 떨어지는 방향(복사점)을 화면에서 확인합니다.

**시나리오 4. 밤 시간의 정차·대기 (전기차 충전 등)**
1. 밤에 충전소에서 30분을 기다리는 동안, 지금 머리 위에 떠 있는 별과 오늘의 별자리 이야기를 짧게 즐깁니다.

## 5. 개발 계획

### 개발 환경
- Android Studio, Kotlin, minSdk API 28 / compileSdk API 34, Gradle 8 이상
- 검증 환경: Pleos Connect Emulator(Virtual Console로 위치, 기어, 조명 상태 조작)
- 화면 렌더링: Android 2D 렌더링(Canvas, 필요 시 OpenGL ES)으로 가볍게 구현

### Pleos Connect SDK / API 사용 계획

| 기능 | SDK / API | 사용 내용 | 권한 |
|---|---|---|---|
| 현재 위치·방향 | **FusedLocation SDK** | `registerFusedLocationCallback()`로 위도, 경도, 고도, **heading(차량 방향)** 수신 → 하늘 계산의 기준 | `pleos.car.permission.FUSED_LOCATION` |
| 관측 모드 조명 | **Vehicle SDK – Light** | `setCabinLightSwitch()`, `setReadingLightSwitch()`, `setAmbientLightSwitch()`로 실내등·독서등·무드등 모두 끄기, 종료 시 원래 상태로 복원 | `pleos.car.permission.CAR_LIGHTS`, `CONTROL_CAR_LIGHTS` |
| 선루프 관측 모드 | **Vehicle SDK – Window** | 천장 창(`ROOF_TOP_1`, `ROOF_TOP_2`) 대상. `getCurrentWindowBlindPosition()`/`registerWindowBlindPosition()`으로 가림막 상태 감지, `moveWindowBlind()`로 가림막 열기, `getCurrentWindowPosition()`으로 유리 상태 확인 | 읽기 `pleos.car.permission.CAR_WINDOWS`, 제어 `pleos.car.permission.CONTROL_CAR_WINDOWS` |
| 관측 명소 길안내 | **NaviHelper SDK** | `requestRoute()`로 관측 명소 목적지 설정, `getCurrentLocationInfo()`로 현재 위치 보조 | `pleos.car.permission.NAVI_ROUTE`, `NAVI_ROUTE_SEARCH` |
| 설명 듣기·이야기 낭독 | **TextToSpeech SDK** (현재 프로토타입은 Android 기본 TTS) | 별·별자리 설명과 이야기 음성 출력. Pleos TTS SDK가 열리면 교체 | SDK 안내에 따름 |
| 음성 질문 | **Gleo Interface** | `assets/schema.json`에 3개 기능(`DESCRIBE_SKY_OBJECT`, `FIND_SKY_OBJECT`, `TELL_CONSTELLATION_STORY`) 등록. 기능 이름을 action으로 받는 intent-filter, `ACTION_PARAM` 파싱, `APP_ACTION_RESPONSE` 브로드캐스트로 결과(이름, 종류, 밝기, 거리, 방향, 이야기) 반환 | - |
| 정차·주행 판단 | **AAOS CarUxRestrictions**, `GEAR_SELECTION` | 주행 제한 시 화면 숨김 및 상태 저장, 정차 시 복귀 | `android.car.permission.CAR_POWERTRAIN` |

### 천문 계산과 데이터
- **별 위치 계산**: 현재 시각과 위치로 항성시를 구하고, 적경·적위를 지평 좌표(고도·방위각)로 변환합니다. 행성과 달은 공개된 천문 알고리즘으로 계산하며, 서버 없이 차 안에서 모두 처리합니다.
- **별 데이터**: 공개 항성 목록(HYG 데이터베이스 등, 출처 표기)에서 맨눈으로 보이는 밝기(6등급 이하)의 별 약 9천 개를 사용합니다.
- **별자리**: 국제천문연맹 88개 별자리 + 우리 전통 별자리 일부. 이야기 콘텐츠는 직접 작성합니다.

### 성능·안정성 기준
- Pleos 앱 성능 가이드 기준을 따릅니다: RAM 400MB 이하, 정차 중 CPU 25% 이하, 앱 실행 10초 이내.
- 별 데이터와 이야기를 기기에 내장해 네트워크 없이도 동작합니다. 산이나 캠핑장처럼 통신이 약한 곳에서도 쓸 수 있습니다.

### SDK 제공 상태에 따른 대안
- FusedLocation SDK를 쓸 수 없는 경우: NaviHelper의 현재 위치 정보로 대체합니다.
- TTS SDK를 쓸 수 없는 경우: 이야기를 자막과 그림 중심으로 제공합니다.
- 조명 제어 권한이 허용되지 않는 경우: 조명을 직접 끄도록 안내합니다.
- 선루프 제어 권한이 허용되지 않는 경우: 읽기 권한으로 가림막 열림을 감지해 머리 위 하늘로 자동 전환하고, 가림막을 열도록 음성으로 안내합니다.

## 6. 기대효과 및 발전 가능성

### 사용자 가치
- **가족**: 차 안이 아이와 함께하는 작은 천문대가 되고, 별자리 이야기로 자연스러운 과학·인문 교육이 됩니다.
- **차박·캠핑족, 커플**: 별 보러 가는 여행의 계획(명소, 이벤트)부터 현장 관측까지 한 번에 해결합니다.
- **현대자동차그룹**: '차 안에서 머무는 시간'의 가치를 높이고, 야간 여가와 여행에 어울리는 브랜드 경험을 제공합니다.

### 타깃 고객
- **1차**: 유아~초등 자녀를 둔 30~40대 부모 (가족 캠핑·차박)
- **2차**: 20~30대 커플과 야간 드라이브·별 보기 여행을 즐기는 사용자
- **3차**: 밤 시간에 정차·대기가 잦은 전기차 오너

### 예상 사용 지표 (가정 기반)
- **예상 MAU** = Pleos Connect 탑재 차량 수 × 설치율 × 월간 활성 비율 [탑재 차량 수 확인 후 계산]
  - 예시 가정: 설치율 [ ]%, 설치자 중 월간 활성 [ ]%
- **리텐션 설계**
  - **계절이 바뀌면 하늘이 바뀝니다.** 계절별 별자리와 이야기를 새로 공개해 다시 찾아올 이유를 만듭니다.
  - 유성우·월식 같은 **천문 이벤트 알림**으로 정기적인 재방문을 유도합니다.
  - **별자리 도감 수집**으로 "아직 못 본 별자리"를 찾으러 가는 동기를 만듭니다.

### 수익 모델
- **기본 무료 + 프리미엄**: 전체 이야기 라이브러리, 심화 천체 정보, 계절 특별 콘텐츠
- **제휴**: 천문대·과학관 프로그램, 캠핑장·글램핑 예약, 지자체 별빛 관광 상품 연계
- **교육 콘텐츠**: 아이 대상 별자리 교육 패키지, 학교·기관 연계

### 향후 확장
- **HUD·앞유리 AR**: 실제 하늘 위에 별자리 선을 겹쳐 보여주기
- **스마트 글라스 연동**: 투명도가 바뀌는 유리를 갖춘 차량에서 유리 투명도까지 자동 조절
- **뒷좌석 화면 연동**: 뒷좌석 아이가 따로 이야기를 즐기는 모드
- **해외 출시**: 남반구 별자리, 각 나라의 별 이야기로 현지화
- **날씨·구름 정보 연동**: 오늘 밤 관측 가능 지수 제공
